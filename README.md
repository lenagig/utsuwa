# 器


## 必要なもの

- Node.js
- npm

動作確認済みの環境:

```bash
node --version
npm --version
```

このプロジェクト作成時点では、Node.js `v22.18.0` / npm `10.9.3` で動作確認しています。

## 初回セットアップ

リポジトリを取得したあと、プロジェクト直下で依存関係をインストールします。

```bash
npm install
```

## 開発サーバーの起動

```bash
npm run dev
```

起動できたら、ブラウザで以下を開きます。

```text
http://localhost:3000
```

## 技術構成
